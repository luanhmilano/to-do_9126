# Atividades de Engenharia de Software

Este repositório contém duas atividades práticas da disciplina de Engenharia de Software.

## Estrutura do Projeto

### 1_atividade--9126
Aplicação web desenvolvida com React e Vite para gerenciamento de tarefas e verificações de qualidade.

**Tecnologias utilizadas:**
- React
- Vite
- CSS Modules
- ESLint

**Como executar:**
```bash
cd 1_atividade--9126
npm install
npm run dev
```

### 2_atividade--lab_todolist
Aplicação web de lista de tarefas desenvolvida com Flask.

**Tecnologias utilizadas:**
- Python
- Flask
- HTML/CSS

**Como executar:**
```bash
cd 2_atividade--lab_todolist
pip install -r requirements.txt
python app.py
```
